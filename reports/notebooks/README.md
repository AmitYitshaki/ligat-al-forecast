## איך פותחים

- מורידים את הקובץ, או עושים clone לריפו, ופותחים אותו בדפדפן. GitHub מציג קובץ HTML כקוד ולא כעמוד.
- הגרפים אינטראקטיביים: אפשר לרחף עם העכבר מעל נקודה, להגדיל אזור ולהסתיר סדרה מהמקרא.
- במחברות 01 ו-02 הגרפים נטענים מהרשת, ולכן צריך חיבור לאינטרנט. במחברות 03–05 הם כלולים בקובץ. הנוסחאות נטענות מהרשת בכל המחברות.

## מתי מעדכנים

רק כשמחברת ממוזגת ל-`main`, או בהחלטה של עמית. כל ייצוא מוסיף כמה MB להיסטוריה של הריפו.

**איך נוצרו הקבצים:**
- **01–04:** ייצוא ל-HTML מהפלטים השמורים של ההרצה המלאה האחרונה.
- **03 ו-04:** הגרפים נשמרו בלי HTML, ולכן הם הומרו ל-HTML בזמן הייצוא.
- **05:** הייצוא של ההרצה המלאה ב-E4d.
