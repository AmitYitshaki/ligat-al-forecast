# T-004: סקרייפר עמודי משחק

**סטטוס:** פתוחה
**מבצע:** Codex
**תלויות:** T-003 (צריך את רשימת ה-`game_id`)

## מטרה
למשוך את עמוד המשחק לכל משחק ששוחק (כ-4,500) ולשמור אותו גולמי.

## הסבר כדורגלני
התוצאה הסופית מספרת רק את הסוף. עמוד המשחק מספר את הסיפור: מי הוביל במחצית, מתי נכבשו השערים, האם מישהו הורחק, ומי אימן. מכאן באים פיצ'רים כמו "קבוצה שיודעת לשמור על יתרון" ו"משחק בעשרה".

## שלב א: בדיקת היתכנות (חובה לפני גרידה מלאה)
העמוד נטען דינמית; `fetch` ישיר מחזיר מעטפת ריקה. לבדוק לפי הסדר:
1. נקודת קצה נסתרת (לשונית Network בדפדפן).
2. בקשה עם עוגיות/כותרות של דפדפן.
3. Playwright (דפדפן אמיתי, איטי יותר).

**תוצר שלב א:** 10 משחקים מעונות שונות נמשכו בהצלחה; זמן משוער לכל ה-4,500; המלצה. **⏸ אישור עמית לפני שלב ב.**

## שלב ב: גרידה מלאה
- פלט: `data/raw/ifa/games/{season_id}/{game_id}.html` + `manifest.json`.
- השהיה ≥ 2 שניות. ב-Playwright: דפדפן אחד, עמוד אחד בכל פעם.
- המשכיות: ריצה שנקטעה ממשיכה מהמקום שעצרה.
- מצב `live`: רק משחקים חדשים מאז הריצה הקודמת.

## קריטריוני קבלה
- [ ] שלב א הושלם ואושר.

- [ ] טסטים עם עמודים שמורים מ-2007 (בלי הרכבים) ומ-2012+ (עם הרכבים).
