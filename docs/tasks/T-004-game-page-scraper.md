# T-004: סקרייפר עמודי משחק

**סטטוס:** פתוחה
**מבצע:** Codex
**תלויות:** T-003 (צריך את רשימת ה-`game_id`)

## מטרה
למשוך את עמוד המשחק לכל משחק ששוחק (כ-4,500) ולשמור אותו גולמי.

## הסבר כדורגלני
התוצאה הסופית מספרת רק את הסוף. עמוד המשחק מספר את הסיפור: מי הוביל במחצית, מתי נכבשו השערים, האם מישהו הורחק, ומי אימן. מכאן באים פיצ'רים כמו "קבוצה שיודעת לשמור על יתרון" ו"משחק בעשרה".

## שלב א: בדיקת תקינות ראשונית (10 משחקים)
בסקירה של 9.10.2026 אומת שהעמוד הוא HTML סטטי רגיל וקריאת `GET` ישירה מחזירה את כל הנתונים (אין צורך ב-Playwright).
1. לוודא שליפה תקינה של 10 משחקים מדגמיים מעונות שונות (2006/07 עד 2026/27).
2. אימות מבנה ה-HTML והשדות המרכזיים.

## שלב ב: גרידה מלאה
- פלט: `data/raw/ifa/games/{season_id}/{game_id}.html` + `manifest.json`.
- היקף: כ-4,800 עמודים.
- השהיה ≥ 2 שניות (זמן משוער: כ-2.5 עד 3 שעות).
- המשכיות: ריצה שנקטעה ממשיכה מהמקום שעצרה על בסיס קבצים קיימים.
- מצב `live`: רק משחקים חדשים מאז הריצה הקודמת.

- [ ] טסטים עם עמודים שמורים מ-2006/07 ומ-2010/11+.
