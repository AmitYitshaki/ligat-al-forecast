# T-006: מחקר חוקי הליגה (שוברי שוויון ולוח פלייאוף)

**סטטוס:** פתוחה
**מבצע:** Claude Code (אנליסט), בליווי עמית
**תלויות:** — (אפשר במקביל ל-T-002)

## מטרה
לתעד בדיוק איך ההתאחדות קובעת מיקום כשיש שוויון בנקודות, ואיך נבנה לוח הפלייאוף, לכל תקופה.

## הסבר כדורגלני
בעונה צמודה, ההבדל בין אליפות למקום שני, או בין הישרדות לירידה, יכול להיות שובר שוויון. סימולטור עם הכלל הלא נכון ייתן הסתברויות שגויות בדיוק ברגעים החשובים.

## קלט ופלט
- קלט: תקנון הליגות באתר ההתאחדות (`/association/aboutassociation/rules/`), ארכיון התקנונים, ויקיפדיה.
- פלט: סעיף ב-`docs/DATA_SOURCES.md` + שדות `tiebreakers` ו-`playoff_schedule` ב-`config/seasons.yaml`.

## קריטריוני קבלה
- [ ] סדר שוברי השוויון, עם ציטוט סעיף התקנון ותאריך.
- [ ] בדיקה מול לפחות 2 מקרי שוויון אמיתיים בדאטה (אחרי T-003), שהסדר בטבלה הרשמית תואם לכלל.
- [ ] כלל קביעת המארחת בפלייאוף התחתון (סיבוב אחד, 7 מחזורים).

## מחוץ להיקף
מימוש בסימולטור.
