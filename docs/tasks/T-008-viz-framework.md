# T-008: תשתית ויזואליזציה

**סטטוס:** פתוחה
**מבצע:** Codex
**תלויות:** T-001 (אפשר במקביל ל-T-002–T-005)

## מטרה
מנגנון שבו כל גרף בפרויקט מוגדר פעם אחת כפונקציה, ונבנה מחדש מהדאטה הנוכחי בפקודה אחת. פירוט מלא: `docs/VISUALIZATION.md`.

## הסבר כדורגלני
גרף טוב מראה בשנייה את מה שטבלה מסתירה: איך המאבק על האליפות התפתח, איפה יתרון הביתיות נעלם, איזו קבוצה מתמוטטת בסוף משחקים.

## קלט ופלט
- פלט: מודול `ligat/viz/` עם `ChartSpec`, `registry`, ערכת עיצוב, ו-CLI `ligat viz build`. גלריית HTML ב-`reports/gallery/index.html`.

## קריטריוני קבלה
- [ ] `ChartSpec` עם השדות מ-`VISUALIZATION.md` (כולל `football_question`).
- [ ] רישום גרף בדקורטור אחד; `ligat viz list` מציג את כל הגרפים.
- [ ] `ligat viz build` בונה הכול; `--stage data` / `--chart NAME` לבנייה חלקית.
- [ ] כל גרף נשמר כ-HTML אינטראקטיבי + PNG.
- [ ] גלריה אחת שמציגה את כל הגרפים לפי שלב, עם השאלה שכל גרף עונה עליה ותאריך הבנייה.
- [ ] בנייה מחדש מזהה שהדאטה השתנה (hash של קבצי הקלט) ובונה רק את מה שהושפע.
- [ ] טסט: כל גרף רשום נבנה בהצלחה על דאטה דמה קטן.
- [ ] שני גרפי דוגמה עובדים מקצה לקצה.

## מחוץ להיקף
