# T-005: פענוח עמודי משחק ובניית דאטה סטים מפורטים

**סטטוס:** במימוש — PR לסקירת Claude Code ועמית
**מבצע:** Codex
**תלויות:** T-004

## מטרה
מהעמודים הגולמיים לארבעה דאטה סטים: `game_details`, `goals`, `red_cards`, `coaches` (לפי `docs/DATA_DICTIONARY.md`).

## הסבר כדורגלני
- **תוצאת מחצית + דקות שערים וכרטיסים לפי דקה (מ-2006/07):** יכולת להחזיק יתרון, קאמבקים, שערים מאוחרים, משחק בעשרה (כרטיסים אדומים קיימים מ-2006/07 בציר הזמן).
- **הרכבים ומאמנים (מ-2010/11):** זיהוי החלפת מאמן ("אפקט המאמן החדש") מוקדם מהמתוכנן.

## קלט ופלט
- קלט: `data/raw/ifa/games/` (4,842 עמודי משחק תקינים שנמשכו ב-T-004 בדחיסת gzip), `data/clean/matches.parquet`.
- פלט: ארבעה קובצי Parquet ב-`data/clean/` לפי `docs/DATA_DICTIONARY.md`, וקובץ Excel מאוחד ומעודכן.

## קריטריוני קבלה
- [ ] תוצאת המחצית + הסופית בעמוד המשחק = התוצאה ב-`matches` (בדיקה הצלבתית לכל משחק).
- [ ] מספר השערים ב-`goals` לכל משחק = התוצאה הסופית. פערים נרשמים בדוח, לא נבלעים.
- [ ] שדות שלא קיימים בעונות הישנות הם `null` מפורש, לא 0.
- [ ] Golden files מ-2006/07, 2010/11 ו-2026/27.
- [ ] **ייצוא Excel גרסה 0.3 (`data/clean/ligat_al_data_0.3.xlsx`):** הקובץ יכלול את כל 8 הלשוניות (4 הקיימות: `matches`, `fixtures`, `round_tables`, `final_tables` + 4 החדשות: `game_details`, `goals`, `red_cards`, `coaches`) לצפייה נוחה ומעקב ויזואלי של עמית.

## מימוש מאושר ופתרון 68 הפערים (12.10.2026)

- קריאה מאומתת של gzip ושל תוכנו מול manifest שהושלם; 4,831 משחקים בלבד בפירוט (לאחר החרגת 11 הטכניים).
- סכמות Pandera לכל ארבעת הפלטים, כולל added_time, is_second_yellow, half, is_first_half_stoppage, ht_conflict, goals_available.
- **כלל שיוך שערים למחצית (פותר 54 מקרי תוספת זמן):** לכל קבוצה, השערים הראשונים לפי סדר הדקות, כמספר שערי המחצית שלה בכותרת, שייכים למחצית הראשונה (`half=1`). דקה מעל 45 במחצית ראשונה מסומנת כ-`is_first_half_stoppage=True`.
- **קובץ חריגים מתועד (`config/game_detail_exceptions.yaml`):**
  - 13 משחקי `ht_conflict` (קבוצה ב'): `game_details.ht_conflict = True`, המחצית נשמרת כבכותרת, `goals.half = null`.
  - משחק 1 `goals_available=False` (קבוצה ג', משחק 864982): `game_details.goals_available = False`, אין שורות ב-`goals`.
  - סתירה חדשה שלא מופיעה בקובץ החריגים תכשיל את הבנייה!
- team_id בשער עצמי הוא הצד היריב של המבקיע (הקבוצה שהשער נזקף לזכותה).
- מאמן חסר מקבל שתי שורות קבוצה עם null בשדות החסרים.
- has_lineups ו־has_coaches דורשים תוכן בשני הצדדים; has_timeline כולל סמני זמן.
- דקת כרטיס -1 נשמרת כ־null ומופיעה כאזהרה בדוח, בלי להשמיט את הכרטיס (12 מקרים).
- הצלבות סוף/מחצית ודגלים מאומתות לפני פרסום Parquet; דוח game_details_validation.json.
