- **`theme.py`:** ערכת עיצוב ציבורית לפי `VISUALIZATION.md` §2–§3, במקום `_finish` (אחרי T-012).
- **תצוגה במחברת 02:** פערי S4 D17 ו-D18 (T-011).
- **ברירת המחדל של `load_analysis_tables`:** היום היא טוענת את עונות 8–27, ולכן קריאה בלי `seasons=` טוענת גם עונות מבחן. כך קרה באירוע של T-013 B1a. **ההצעה:** ברירת מחדל של 8–25, וטעינת עונות המבחן רק בבקשה מפורשת. השינוי נוגע במחברות ובטסטים, ולכן צריך לבדוק שכל הפלטים זהים.
