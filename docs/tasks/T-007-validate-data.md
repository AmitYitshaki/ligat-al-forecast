# T-007: אימות הדאטה וקונפיגורציית העונות

**סטטוס:** פתוחה
**מבצע:** Claude Code (QA ואנליסט)
**תלויות:** T-003, T-005

## מטרה
להוכיח שהדאטה נכון לפני שבונים עליו מודל.

## הסבר כדורגלני
אם חסר משחק אחד, הטבלה של עונה שלמה שגויה, וכל מה שנלמד ממנה מעוות.

## קלט ופלט
- קלט: `data/clean/`, `config/seasons.yaml`.
- פלט: `docs/reports/R-001-data-validation.md`.

## קריטריוני קבלה
- [ ] לכל עונה: מספר משחקים תואם לפורמט.
- [ ] לכל עונה ולכל מחזור: `points_model` מחושב = נקודות רשמיות, **חוץ מהורדות**. כל פער שאינו חלוקה מסווג כהורדה ונרשם (לא מתקנים, לפי ההחלטה להתעלם מהורדות).
- [ ] `config/seasons.yaml` מאומת לכל עונה (`verified: true`).
- [ ] הצלבה: `game_details` מול `matches` (מ-T-005).
- [ ] רשימת חריגים: משחקים טכניים, נדחים, אצטדיונים שאולים.
- [ ] גרפי האימות מ-T-009 מצורפים לדוח.
