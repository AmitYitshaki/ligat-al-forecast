# T-003: פענוח ובניית ארבעת הדאטה סטים הבסיסיים

**סטטוס:** בבדיקה — המימוש המקומי הושלם, ממתין לסקירת Claude Code ב־PR
**מבצע:** Codex
**תלויות:** T-002

## מטרה
מהקבצים הגולמיים לארבעה דאטה סטים ב-`data/clean/`: `matches`, `fixtures`, `round_tables`, `final_tables`.

## הסבר כדורגלני
כאן התוצאות הופכות למשהו שאפשר לחשוב עליו: מי ניצח, באיזה מגרש, איך נראתה הטבלה בכל רגע בעונה, ומה עוד נשאר לשחק.

## קלט ופלט
- קלט: `data/raw/ifa/rounds/` (עונות `season_id` 8–28), `config/seasons.yaml`.
- פלט: קבצי Parquet ב-`data/clean/` לפי `docs/DATA_DICTIONARY.md`, מאומתים בסכמות pandera:
  - `matches`: כל משחקי הליגה ששוחקו (ללא משחקי מבחן עלייה).
  - `fixtures`: משחקים עתידיים בעונה הנוכחית.
  - `round_tables`: טבלאות מצב אחרי כל מחזור.
  - `final_tables`: טבלאות סיום עונה.

## קריטריוני קבלה
- [x] **זיהוי קבוצות נקי:** חילוץ `team_id` של בית וחוץ ישירות מהתכונות `data-team1` ו-`data-team2` בשורת המשחק (ללא פענוח מחרוזות שמות).
- [x] **תיקון התוצאה ההפוכה והשערים ההפוכים:** `"a - b"` בטקסט המשחק = חוץ a, בית b; בטבלה `"a-b"` = ספגה a, הבקיעה b (מלווה בטסטים לפי `DATA_SOURCES.md`).
- [x] **תאריכים ונכונות זמנים:** עמודת `date` מפוענחת כ-`datetime64` עם אזור זמן `Asia/Jerusalem`, לטובת חישובי `as_of` כרונולוגיים מדויקים (משחקים נדחים מקבלים את מועד המשחק בפועל).
- [x] **טיפול במשחקי מבחן עלייה:** מחזורי "מבחן עלייה" (סבב מבחן מול הלאומית, למשל ב-2009/10 וב-2010/11) מוחרגים מטבלת `matches` הרגילה.
- [x] **סטטוס תוצאה ומשחקי `void`:** תמיכה בערכי `status` (`played`, `awarded`, `void`). משחק שבו שתי הקבוצות נענשו באי-קבלת נקודות (סעיף 64, כדוגמת דרבי 2014/15) מקבל סטטוס `void` ואינו מזכה בנקודות ב-`points_model`.
- [x] **נקודות לפי חוקי הליגה:** `points_model` = 3×נ + ת, עם חלוקת נקודות (קיזוז בעיגול למעלה) לפי `seasons.yaml` בעונות **2009/10 ו-2010/11 בלבד** (ללא קיזוז ב-2011/12). הורדות נקודות מבית הדין מוחרגות מ-`points_model`, ו-`points_official` נשמר לאימות בלבד.
- [x] **לוח עתידי (`fixtures`):** נבנה משורות ללא תוצאה בעונה הנוכחית, עם מפתח `(season_id, round, home_team_id, away_team_id)`.
- [x] **ניקוי אצטדיונים:** הסרת הקידומת "(סגור)" ושמירת השם המקורי ב-`venue_raw`.
- [x] **מיפוי קבוצות ראשוני:** יצירת טיוטת `config/teams.yaml` עם מזהה `team_id`, שם קנוני בעברית, ורשימת שמות נרדפים (`aliases`) שנצפו בדאטה.
- [x] **Golden files:** טסטים מול קבצי מחזור שמורים מכל מבנה ליגה (12 קבוצות, 16 עם קיזוז, 16 ללא קיזוז, 14 קבוצות, ומחזור עתידי).
