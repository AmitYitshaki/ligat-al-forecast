# מקורות דאטה: פירוט טכני

> מה נבדק בפועל, איך לגשת, ומה צריך לדעת לפני שכותבים קוד.
> נבדק ידנית בדפדפן ב-8.10.2026; עודכן אחרי סקירה מקומית ב-9.10.2026 ([R-000](reports/R-000-data-sources-recon.md)). כל מה שמסומן "לא אומת" צריך בדיקה לפני שבונים עליו.

## 1. אתר ההתאחדות: טבלאות ומשחקים לפי מחזור (מקור ליבה)

### נקודת הקצה

```
GET https://www.football.org.il/Components.asmx/League_AllTables
    ?league_id=40&season_id={S}&box=0&round_id={R}
```

| פרמטר | ערך | הערה |
| --- | --- | --- |
| `league_id` | 40 | ליגת העל |
| `season_id` | 8–28 | 8 = 2006/07, 9 = 2007/08, ..., 28 = 2026/27. נוסחה: `season_id = שנת_התחלה − 1998` |
| `box` | 0 | עם 0 עובד לכל המחזורים, כולל פלייאוף |
| `round_id` | 1..N | מספר מחזור רץ לאורך כל העונה (גם בפלייאוף) |

### מבנה התגובה

XML מסוג `ResponseData`. השדה `HtmlData` מכיל HTML. בתוכו שורות `.table_row`, ובכל שורה תאים `.table_col`.

- **שורת טבלה:** `href` מכיל `team-details/?season_id=..&team_id=..`. תאים: מיקום, קבוצה, משחקים, ניצחונות, תיקו, הפסדים, שערים, נקודות.
- **שורת משחק ששוחק:** `href` מכיל `games/game/?game_id=..`. תאים: תאריך, משחק ("בית - חוץ"), מגרש, שעה, תוצאה.
- **שורת משחק עתידי:** אותם תאים, אבל **בלי `href` ובלי תוצאה.** כלומר אין `game_id` עד שהמשחק משוחק.

כל תא מתחיל בתווית (למשל "מיקום1", "נקודות15"). צריך להסיר את התווית לפני פענוח.

### דוגמאות אמיתיות (מחזור 5, עונת 2026/27)

```
מיקום1 | קבוצהמכבי ת"א | משחקים5 | ניצחונות5 | תיקו0 | הפסדים0 | שערים6-18 | נקודות15
תאריך19/09/2026 | משחקמכבי נתניה - מכבי ת"א | מגרשנתניה אצטדיון מרים | שעה20:02 | תוצאה2 - 1
```

המשחק השני: מכבי נתניה בבית, מכבי ת"א בחוץ. בטקסט התוצאה מופיעה כ-`"2 - 1"`, ופירושה **חוץ קודם**: מכבי ת"א (חוץ) 2, מכבי נתניה (בית) 1. אומת מול עמוד המשחק (מבקיעים: עוז בילו לנתניה; דור פרץ וטברנייר למכבי ת"א) ומול הטבלה (מכבי ת"א 5 ניצחונות מ-5).

### היקף

כ-36 מחזורים × 20 עונות ≈ 700 בקשות. בהשהיה של 2 שניות: כ-25 דקות לכל ההיסטוריה.

## 2. אתר ההתאחדות: עמוד משחק

```
https://www.football.org.il/leagues/games/game/?game_id={ID}
```

נדגם משחק אחד מכל עונה (9.10.2026), כלומר כל שורה בטבלה נשענת על משחק אחד לעונה בלבד.

| מידע | מ- |
| --- | --- |
| תוצאה סופית + **תוצאת מחצית** | 2006/07 |
| **מבקיעים ודקות** | 2006/07 |
| שופטים | 2006/07 |
| **כרטיסים צהובים ואדומים עם דקה** (בציר "מהלך משחק") | 2006/07 |
| הרכבים, מחליפים, דקות חילוף | 2010/11 |
| **מאמן כל קבוצה במשחק** | 2010/11 |
| שופט VAR | 2019/20 |

**למה זה מעניין כדורגלית** (פיצ'רים מועמדים, נכנסים אם עוברים ablation):
- **תוצאת מחצית ודקות שערים:** קבוצה שמחזיקה יתרון מול קבוצה שמתמוטטת בדקות האחרונות; יכולת קאמבק. זמין לכל התקופה.
- **כרטיס אדום:** משחק ב-10 שחקנים לא משקף את החוזק האמיתי. אפשר להוריד לו משקל באימון.
- **מאמן:** זיהוי החלפות מאמן אוטומטית מ-2010/11, בלי מקור חיצוני.

**גישה:** `GET` רגיל מחזיר HTML מלא (כ-250KB לעמוד). **לא צריך Playwright.** ההערכה הקודמת ("מעטפת ריקה") התבררה כשגויה. כ-4,800 עמודים כולל 2006/07; בהשהיה של 2 שניות כשלוש שעות.

## 2א. חוקי הליגה (T-006; פירוט ומקורות ב-[R-003](reports/R-003-league-rules.md))

- **שוברי שוויון** (תקנון האליפות 2026, סעיף 50): נקודות ← הפרש שערים ← ניצחונות ← שערי זכות ← אותו סדר במפגשים הישירים ← משחק מכריע. בשוויון שקובע רק את השיבוץ לפלייאוף, מכריע המיקום בעונה הקודמת. ב-2006/07–2007/08, לפי ויקיפדיה, לא היו "ניצחונות" בסדר.
- **פלייאוף** (סעיף 52): עליון 1–6, שני סיבובים; תחתון 7–14, סיבוב אחד; הנקודות נגררות במלואן. הביתיות בתחתון לפי תבנית קבועה של דירוג (7–10 מארחות 4), שנמצאה זהה ב-2022/23 וב-2023/24.
- **תוצאות טכניות** (סעיף 64): 0:3 לקבוצה האשמה; **0:0 בלי נקודות** כששתיהן אשמות. דוגמה: דרבי ת"א 2014/15.
